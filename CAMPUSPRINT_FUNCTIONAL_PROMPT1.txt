Create these tables exactly:

-- USERS (extends Supabase auth.users)
profiles (
  id            uuid references auth.users primary key,
  full_name     text,
  student_id    text unique,
  department    text,
  year          int,
  wallet_balance decimal(10,2) default 0,
  role          text default 'student', -- student | faculty | admin
  created_at    timestamptz default now()
)

-- PRINT JOBS
print_jobs (
  id            uuid primary key default gen_random_uuid(),
  user_id       uuid references profiles(id),
  file_name     text not null,
  file_url      text not null,        -- Supabase storage URL
  file_size_mb  decimal(6,2),
  page_count    int,
  color_mode    text,                 -- bw | color
  sides         text,                 -- simplex | duplex
  page_range    text,                 -- e.g. "1-12" or "all"
  copies        int default 1,
  sheet_count   int,
  kiosk_id      text,
  status        text default 'pending',
                -- pending | processing | sent | ready | collected | failed
  total_amount  decimal(8,2),
  otp           text,
  otp_expires_at timestamptz,
  payment_id    text,                 -- Razorpay payment ID
  payment_status text default 'unpaid', -- unpaid | paid | failed | refunded
  created_at    timestamptz default now(),
  updated_at    timestamptz default now()
)

-- KIOSKS
kiosks (
  id            text primary key,     -- e.g. "LIB-04"
  name          text,
  location      text,
  building      text,
  floor         text,
  is_online     boolean default true,
  queue_count   int default 0,
  last_ping     timestamptz
)

-- TRANSACTIONS
transactions (
  id            uuid primary key default gen_random_uuid(),
  user_id       uuid references profiles(id),
  print_job_id  uuid references print_jobs(id),
  amount        decimal(8,2),
  method        text,                 -- upi | qr | wallet | card
  razorpay_order_id text,
  razorpay_payment_id text,
  status        text,                 -- created | paid | failed
  created_at    timestamptz default now()
)

-- CLOUD DOCUMENTS
cloud_documents (
  id            uuid primary key default gen_random_uuid(),
  user_id       uuid references profiles(id),
  provider      text,                 -- gdrive | dropbox | local
  file_name     text,
  file_size_mb  decimal(6,2),
  mime_type     text,
  provider_file_id text,
  storage_url   text,
  created_at    timestamptz default now()
)

Row Level Security: enable on all tables.
  profiles: user can only read/update their own row
  print_jobs: user can only read their own jobs
  transactions: user can only read their own transactions
  cloud_documents: user can only read their own documents
  kiosks: all authenticated users can read

SECTION 3 — API ROUTES (Next.js /app/api/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Build every one of these. Each must handle errors and return
consistent { data, error } JSON responses.

AUTH
  POST /api/auth/login        → email + password → session
  POST /api/auth/logout       → clear session
  POST /api/auth/register     → create profile row after signup
  GET  /api/auth/me           → return current user + wallet balance

FILE UPLOAD
  POST /api/upload            → multipart/form-data → upload to
                                Supabase Storage → return file URL,
                                page count (use pdf-lib to count pages),
                                file size
  DELETE /api/upload/:id      → remove file from storage

PRINT JOBS
  POST /api/print-jobs        → create print job record, calculate
                                cost, return job ID + total amount
  GET  /api/print-jobs        → list all jobs for current user
  GET  /api/print-jobs/:id    → get single job with status
  PATCH /api/print-jobs/:id/status → update job status (kiosk webhook)

COST CALCULATION (pure function, also expose as API)
  POST /api/calculate-cost
    body: { pageCount, colorMode, sides, copies, pageRange }
    returns: { sheetCount, baseCost, serviceFee, total }

    Rules:
      B&W simplex   → ₹2.00/sheet
      B&W duplex    → ₹1.75/sheet (paper saving)
      Color standard→ ₹8.00/sheet
      Color glossy  → ₹15.00/sheet
      Service fee   → ₹2.00 flat
      Faculty discount → 10% if role === 'faculty'

PAYMENT
  POST /api/payment/create-order
    → create Razorpay order
    → create transaction record (status: created)
    → return { orderId, amount, currency, keyId }

  POST /api/payment/verify
    → verify Razorpay signature (HMAC SHA256)
    → update transaction status → paid
    → update print_job payment_status → paid
    → update print_job status → processing
    → deduct from wallet if wallet payment
    → return { success, printJobId }

  POST /api/payment/webhook
    → Razorpay webhook handler
    → verify webhook signature
    → handle payment.captured, payment.failed events

OTP
  POST /api/otp/generate
    → generate 6-digit OTP
    → store hashed OTP in print_jobs with 2-minute expiry
    → return { otp, expiresAt } (only to authenticated owner)

  POST /api/otp/verify
    body: { printJobId, otp }
    → verify OTP matches and not expired
    → update print_job status → collected
    → return { success }

  POST /api/otp/refresh
    → generate new OTP, reset timer
    → return { otp, expiresAt }

KIOSKS
  GET  /api/kiosks             → list all kiosks with status
  GET  /api/kiosks/:id         → single kiosk + queue count
  POST /api/kiosks/:id/ping    → kiosk heartbeat (updates last_ping)

QUEUE (Supabase Realtime subscription on client)
  GET  /api/queue/:printJobId  → current position + estimated wait
  Realtime channel: print_jobs:id=eq.{printJobId}
  Subscribe to status changes on the client using supabase.channel()

CLOUD DOCUMENTS
  POST /api/cloud/connect      → store OAuth token for provider
  GET  /api/cloud/files        → list files from connected provider
  POST /api/cloud/import       → copy provider file to Supabase storage

USER / WALLET
  GET  /api/user/history       → paginated print history
  POST /api/user/topup         → add credits via Razorpay
  GET  /api/user/balance       → current wallet balance

SECTION 7 — ERROR HANDLING (every screen)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Every API call must have 3 states rendered in the UI:
  1. Loading  → show spinner or skeleton, disable buttons
  2. Success  → show data, enable next action
  3. Error    → show inline error message, show retry button

Error message placement:
  Form errors → below the field, red text 12px
  API errors  → toast notification (top-right, 4s auto-dismiss)
  Fatal errors → full screen error with "Try Again" button

Toast component spec:
  Position: fixed top-right, 16px from edge
  Width: 320px max, 100% on mobile
  Colors:
    success → bg #ECFDF5, border #10B981, text #065F46
    error   → bg #FEF2F2, border #EF4444, text #991B1B
    info    → bg #EEF2FF, border #2B4EAA, text #1E3A8A
  Auto dismiss: 4000ms
  Manual dismiss: × button
  Stack multiple toasts vertically

Network error handling:
  Detect offline → show "No internet connection" banner
  use navigator.onLine + 'online'/'offline' event listeners

SECTION 11 — SECURITY RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Never expose SUPABASE_SERVICE_ROLE_KEY to the client
  2. Never expose RAZORPAY_KEY_SECRET to the client
  3. Always verify Razorpay webhook signatures server-side
  4. Always verify payment server-side before marking job as paid
  5. OTPs must be hashed (bcrypt) before storing — never store plain
  6. File uploads: validate MIME type server-side, not just extension
  7. File size limit: 50MB enforced server-side
  8. All API routes must check auth session before processing
  9. Rate limit OTP generation: max 5 per job per hour
  10. Supabase RLS is the last line of defense — always enabled
